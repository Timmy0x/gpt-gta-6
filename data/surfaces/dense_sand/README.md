# Dense Sand candidate

[Dense Sand](https://polyhaven.com/a/dense_sand), by **Dimitrios Savva**, is a Poly Haven **CC0-1.0** texture. The [publisher license](https://polyhaven.com/license) permits use and redistribution of the asset. The [public API terms](https://github.com/Poly-Haven/Public-API/blob/master/ToS.md) were read; metadata requests used a project-specific user agent. `info.json` and `files.json` retain the original API metadata, while `acquisition.json` records the retrieval, comparison and license sources.

The three files in `public/surfaces/dense_sand/` are the publisher's unchanged **1024 × 1024 RGB JPEGs**: diffuse color, OpenGL normal, and packed red ambient occlusion / green roughness / blue metalness. Their combined size is **2,359,720 bytes**. Source dimensions are **1.8000000715255737 × 1.8000000715255737 metres** (approximately 1.8 × 1.8 m). Byte sizes and publisher MD5 hashes matched; SHA-256 hashes and exact source URLs are recorded in `proposed-entry.json`.

This is a lighter dry-tan candidate for the dry portion of the beach. Actual source albedo was opened and inspected. Its encoded RGB means are 147.13 / 128.39 / 99.39, compared with 107.96 / 96.12 / 78.73 for the current Sand03 map. These JPEG statistics describe a relative color change, not calibrated reflectance. It remains compacted tan sand with shallow crusts/pits, rather than white quartz sand or a verified Miami/Leonida capture. It should be labeled as an authored material substitute and checked in the game's lighting before adoption.

Other unchanged diffuse candidates inspected were Sand01 (lighter but clay-like and lumpy), Aerial Beach01 (coastal and lighter, but a 30 m source tile unsuitable alone for fine close-up grain), Coast Sand03 (coarse coral/pebbles and 3.8 MB for its three 1K maps), and Damp Beach Sand (still dark/moist). Only the selected Dense Sand set was added to the repository. Current manifest, world materials, exporter and UI were not changed by this preparation.
