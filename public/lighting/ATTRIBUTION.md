# Urban environment lighting

Wide Street 02 by **Sergej Majboroda**, provided by **Poly Haven**, is a free public-domain asset under **CC0 1.0**.

- Source: https://polyhaven.com/a/wide_street_02
- License: https://polyhaven.com/license
- CC0 terms: https://creativecommons.org/publicdomain/zero/1.0/

The 1K HDR panorama is converted with Babylon.js into a 256-pixel-per-face prefiltered environment map with diffuse harmonics and reflection mip levels. It supplies generic urban lighting, not reconstructed Miami/Leonida scenery or live reflections of nearby objects. The source author does not endorse this project.

Source URL, file hashes and conversion verification are retained in `provenance.json`. The local development preparation used Poly Haven's public API; the game serves the prepared asset locally and makes no live Poly Haven API requests. Powered by Poly Haven.
